  their name, so renaming changed it and two members with the same name looked alike. It is now drawn
  from the vault and the member's seat, the same on every screen, so every face changes once with
  this release. It is a visual aid, not a proof of who is behind a seat. Where a name cannot be
  placed on one seat, a neutral face is shown. On the web, the Members screen no longer shows an
